# Warsaw Hussars Cricket Club - Statistics Website

This folder contains the auto-generated static website for Warsaw Hussars Cricket Club statistics.

The website is generated from PDF scorecards using the `generate_website.py` script and is hosted on GitHub Pages.

## Files

- `index.html` - Main webpage
- `style.css` - Styling
- `script.js` - Interactive JavaScript
- `stats.json` - Statistics data

## Updating the Website

To update the statistics with new scorecards:

1. Add new PDF scorecards to the `scorecards/` folder
2. Run: `python generate_website.py`
3. Commit and push changes
4. Website will auto-update on GitHub Pages
